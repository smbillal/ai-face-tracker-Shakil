# ⚡ Cyber HUD - Face & Hand Tracker Pro

An advanced Cyberpunk-themed Web Application featuring real-time **Face Mesh Tracking**, **Hand Gesture Control**, a **Virtual Cyber Keyboard**, and **Voice Command Integration**.

## 🚀 Key Features
- **Face & Hand Tracking:** Powered by MediaPipe for high frame-rate detection.
- **Gesture Controls:**
  - ✌️ **3 Fingers Up:** Automatically captures & downloads a real PNG screenshot.
  - 🖕 **Middle Finger Up:** Opens the Developer Profile HUD.
- **Cyber Virtual Keyboard & Search:** Type using the custom UI and search Google instantly.
- **Voice Commands:** Supports Bangla voice controls (`ডেভলপারের তথ্য`, `স্ক্রিনশট`, `সার্চ`).
- **Interactive Cyber Audio:** Synthesized sound effects via Web Audio API.

## 🛠️ Built With
- **HTML5 / CSS3 / JavaScript (ES6+)**
- **MediaPipe** (Hands & FaceMesh)
- **html2canvas** (Client-side rendering)
- **Web Speech API**
