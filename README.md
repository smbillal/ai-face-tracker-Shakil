
# ⚡ DRIVEVISION AI - Enterprise Dashboard & Fleet System

**DRIVEVISION AI** is a cyberpunk-themed, PWA-ready Web Application designed for Advanced Driver Assistance (ADAS), multi-camera video management (up to 20 channels), live embedded navigation, real-time license plate detection (ALPR), and full user telemetry logging.

## 🚀 Key Features Included

- **Cyberpunk Color Theme:** Black, White, Red, Yellow, Green, and Blue dynamic contrast.
- **Dynamic Multi-Cam Engine:** Supports 1, 2, 3, 4 boxes, expanding automatically up to 20 channels.
- **Live ADAS Distance Grid Lines:** Front and rear camera perspective distance overlays.
- **Embedded Digital Google/Leaflet Maps:** Route navigation, destination pinpointing, expand/minimize option without redirection.
- **Multi-Device Hub:** Wi-Fi auto-discovery, USB Type-C plug-and-play, and Bluetooth sync.
- **User Authentication & 6-Digit Unique ID:** Custom sign-up generating instant unique IDs.
- **Admin Portal (`admin.html`):** Comprehensive user database directory and real-time monitoring system.
- **Data Export:** Export live telemetry and trip logs in CSV or XML format.

## 🛠 File Structure

1. `index.html` - Main Dashboard Interface
2. `style.css` - Custom Cyberpunk Multi-Color Styling
3. `script.js` - Dashboard Core Engine & Features Logic
4. `admin.html` - Dedicated Admin Management Panel
5. `admin.js` - Admin Panel Data Engine
6. `manifest.json` - PWA Manifest File
7. `service-worker.js` - Offline Caching Worker
8. `database.rules.json` - Firebase Security Rules
9. `README.md` - Documentation
